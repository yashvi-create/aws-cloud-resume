☁️ My Cloud-Powered Resume 🚀
Welcome to my first full-stack project! This isn't just a static website; it’s a Serverless App that counts how many people have visited my resume in real-time.

🛠️ The Tech "Magic" Under the Hood:
The Face: HTML/CSS hosted in an Amazon S3 bucket (turned into a website!).

The Brain: An AWS Lambda function written in Python that does the heavy lifting.

The Bridge: Amazon API Gateway—the doorway that lets my website talk to my code.

The Memory: Amazon DynamoDB, where every single visit is saved and remembered.

💡 Why I Built This:
I wanted to move beyond just "clicking buttons" in the AWS console and actually build something that works. This project taught me how to connect different cloud services, handle CORS, and write Boto3 Python scripts to manage data.
